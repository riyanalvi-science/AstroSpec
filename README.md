# AstroSpec

## Computational Analysis of Optical Spectroscopic Data of Active Galactic Nuclei using FITS Files

AstroSpec is a Python-based desktop application for reading, processing, visualizing, and analysing astronomical spectroscopic data stored in FITS files.

## Features

A modular Python-based desktop application for FITS spectroscopy and spectropolarimetric data analysis and visualization.



## Features



- FITS file reading and metadata extraction

- Wavelength calibration from FITS header information

- Raw and normalized spectrum visualization

- Continuum and continuum-subtracted spectra

- Stokes I, Q and U visualization

- Linear polarization analysis

- Error and SNR visualization

- Interactive wavelength/flux point inspection
