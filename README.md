# AstroSpec

## Computational Analysis of Optical Spectroscopic Data of Active Galactic Nuclei using FITS Files

AstroSpec is a Python-based desktop application for reading, processing, visualizing, and analysing astronomical spectroscopic data stored in FITS files.

## Features

* FITS file loading and analysis
* FITS header metadata display
* Wavelength calibration
* Raw spectrum visualization
* Multiple spectrum comparison
* Normalized spectrum
* Continuum spectrum
* Continuum-subtracted spectrum
* Stokes Q and U visualization
* Polarization analysis
* Signal-to-noise ratio analysis
* Error spectrum visualization
* Interactive spectrum inspection

* Python

## Scientific Applications

AstroSpec is designed for the computational analysis of optical spectroscopic observations of Active Galactic Nuclei (AGN) and related astronomical sources.
